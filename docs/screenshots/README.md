# 产品截图拍摄清单

> 按侧边栏顺序排列。将 PNG 放入本目录后，`portfolio.md` / `README.md` 中的占位会自动显示。  
> **建议尺寸：** 宽 1440px 或 1280px；浏览器 100% 缩放；浅色/深色各一套可选（默认深色更贴近 Demo）。

## 命名规范

```
{序号}-{模块}-{页面}.png
```

示例：`03-tags.png`。

**多步骤模块**（抠图 / 活动帖 / 设置 / 管理后台）用 `{模块}-{场景}.png`：

| 模块 | 前缀 | 示例 |
|------|------|------|
| 抠图 Matting | `06-matting-` | `06-matting-step2-crop.png` |
| 活动帖 Campaign | `07-campaign-` | `07-campaign-tab-preview-grid.png` |
| 设置 Settings | `08-settings-tab-` | `08-settings-tab-appearance.png` |
| 管理后台 Admin | `09-admin-` | `09-admin-user-usage.png` |

1. 登录 → 2. 素材 Grid → 3. 上传 → 4. 标签  
5. 文档库 + docx 编辑器 → 6. 知识库 RAG → 7. Chat 流式  
8. **抠图** welcome → step1～step5（同一任务）  
9. **活动帖** sidebar → 配图 → 文案 streaming → done → 预览 → **preview-grid**

11. **管理后台** 用户列表 → 查看 → 基本信息 → AI 用量
